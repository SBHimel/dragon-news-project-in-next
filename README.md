Dragon News is a modern, fast, and fully responsive news application. It allows users to browse news across various categories like Breaking News, Regular News, International, Sports, and more. Built with a focus on performance and SEO using Next.js.

---

### 🚀 Live Demo
- **Live Link:** [dragon-news-project-in-next.vercel.app](https://dragon-news-project-in-next.vercel.app/)

---

### ✨ Key Features
- **📂 Category-wise Filtering:** Browse news easily through a dynamic sidebar with multiple categories.
- **⚡ Server-Side Rendering (SSR):** Optimized for SEO and fast initial page loads.
- **📱 Responsive UI:** Seamless experience on mobile, tablet, and desktop devices.
- **📰 Detailed News View:** Read full articles with high-quality images and formatted content.
- **🎨 Elegant Design:** Clean and professional look using Tailwind CSS.

---

### 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Library:** React.js
- **Styling:** Tailwind CSS
- **Icons:** React Icons / Lucide React
- **Data Fetching:** Fetch API with Next.js caching

---

### 📦 Major Dependencies
- `next`
- `react`
- `react-dom`
- `lucide-react`
- `clsx` & `tailwind-merge`
